# نظام قياس إنتاجية الأطباء — الهيئة العامة للرعاية الصحية (فرع المنيا)

نظام ويب لقياس إنتاجية الأطباء طبقاً لدليل "مشروع قياس الإنتاجية للأطباء 2026-2027":
المؤشرات المالية (F1–F10)، التشغيلية (O1–O6)، السريرية ومؤشر القيمة، تصنيف A–E، وكارت إنتاجية الطبيب (DPC).

- الواجهة: HTML/JS بدون بناء — مستضافة على GitHub Pages.
- البيانات وتسجيل الدخول: Firebase (Authentication + Firestore) — قواعد الأمان في `firestore.rules`.
- **لا توجد أي بيانات أطباء في هذا المستودع.**
- وضع التجربة ببيانات وهمية: أضف `?demo` لنهاية الرابط.
